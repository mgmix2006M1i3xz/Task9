Домашнее задание к работе номер 9

Условие задачи: Написать программу, выводящую на экран заданную геометрическую фигуру (пустой прямоугольник), нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее высоты и ширины в количестве символов пользователем (как на фото с примером).

1. Алгоритм и блок-схема.
   
Алгоритм:

Начало.
Объявить переменные для высоты, ширины и символа.
Запросить у пользователя ввод символа, высоты и ширины.
Запустить внешний цикл for для строк (от 1 до высоты).
Внутри запустить внутренний цикл for для столбцов (от 1 до ширины).
Проверить условие: если это первая/последняя строка ИЛИ первый/последний столбец, вывести символ.
Иначе вывести пробел.
Перейти на новую строку после завершения внутреннего цикла.
Запросить, хочет ли пользователь продолжить (ввод 0 для выхода).
Конец.

2. Реализация программы

#include <stdio.h>
#include <locale.h>

int main() {

    setlocale(LC_ALL, "RUS");
    int height, width, choice;
    char symbol;

    do {
        printf("\nВведите символ из которого будет строиться фигура: ");
        scanf(" %c", &symbol); // Пробел перед %c игнорирует Enter

        printf("Введите высоту: ");
        scanf("%d", &height);

        printf("Введите ширину: ");
        scanf("%d", &width);

        printf("Пустой прямоугольник внутри:\n\n");

        // Внешний цикл по строкам
        for (int i = 1; i <= height; i++) {
            // Внутренний цикл по столбцам
            for (int j = 1; j <= width; j++) {
                // Условие контура
                if (i == 1 || i == height || j == 1 || j == width) {
                    printf("%c", symbol);
                } else {
                    printf(" ");
                }
            }
            printf("\n");
        }

        printf("\nПродолжить? (Да - любое число, Нет - 0): ");
        scanf("%d", &choice);

    } while (choice != 0);

    return 0;
}
